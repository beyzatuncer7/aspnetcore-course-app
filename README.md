# ASP.NET Core MVC Course App

This is a beginner-level ASP.NET Core MVC project created while learning the fundamentals of MVC architecture.

## Features
- ASP.NET Core MVC structure
- Layout, Partial Views, Sections
- Repository pattern (in-memory data)
- Course listing and detail pages
- Bootstrap-based responsive UI

## Technologies
- ASP.NET Core MVC (.NET 7)
- C#
- Razor Views
- Bootstrap

## Purpose
This project was built for learning and practice purposes while following an ASP.NET Core course.
